Astro is a modern static site builder that delivers lightning-fast performance by shipping zero JavaScript by default.

## Key Features

- **Content Collections** — type-safe Markdown/MDX with schema validation
- **Island Architecture** — interactive components only where needed
- **Static by Default** — pre-rendered HTML for maximum speed
- **Framework Agnostic** — use React, Vue, Svelte, or none at all

## Why I Chose Astro

For a blog like this, Astro is the perfect fit. It gives you:

1. Fast page loads
2. Great developer experience
3. Built-in Markdown support
4. Easy deployment anywhere
