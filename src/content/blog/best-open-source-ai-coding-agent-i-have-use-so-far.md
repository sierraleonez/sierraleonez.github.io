Hi Guys, this is my first article in this personal blog

And I will share my experience about the best open source AI Coding agent i have tried.



For context, I'm not a AI-Geek or tech nerd who spent their time dwelling on new stuff and try them out just to so how it's works. Usually I'm checking stuff when I need them for my workflow or to solve a task, and this is the starting point.



My company have given me access to try out Kiro, AI coding agent built by AWS. I'm unfamiliar with it when the first time it reaches my ears, but after short digging, I found out that it is basically the same with Copilot, Cursor, etc. It comes with CLI and IDE mode, while the IDE mode is quite the same with VSCode (since its a fork) and quite comprehensive I can say, the CLI is not packed with same level of feature with its IDE, I found lots of limitation while working with the CLI, and its authentication process is not really pleasant.



I have personally subscribes to other AI coding agent before, Github Copilot which is a gold standard in my opinion, especially for its code-completion. Even if i don't subscribe it any longer, I still use it cause it's way better than Kiro's IDE code-completion. Other things I love the most about Copilot is their subscription price is quite affordable for me ($10 for Pro Plan) when other AI coding Agent cost averagely $20 per month for their lowest tier.



Long story short, the Kiro trial ends and since I already get used to using AI coding agent and I'm utilizing it for my Agentic automated testing, I decided to do quick research about the cheapest AI coding agent out there before I shake deal with Microsoft for Github Copilot plan. 



I'm asking Gemini what is the cheapest AI-coding agent and at the top recommendation it gives me OpenCode. I already heard about OpenCode previously, but I think it just a CLI wrapper for OpenRouter (I always think platform start with 'open' are belong to the same company), but it's not! It's entirely different. It is a AI-coding agent that give you access to [free model](https://opencode.ai/go) and comes with lots of useful tools, such as reviewing code changes, showing file difference, running UI with web server, and the most important is their free models are actually GOOD!!!



First I use it to create THIS exact blog with prompt I generate from gemini, to create a static blog site with Astro, with built-in CMS, and deployable via Github Page. Tt asking me a few question, like what CMS strategy I want to use, what format I want to use, It impresses me cause I used to using Claude and I think only Claude and other high end model posses this ability, but with Big Pickle model its actually possible. There are some issue at first tough, it generating the output in Chinese, which I have to address several times before it fully using English, not a big deal.



Then I asked it to create an agent for mobile automation testing, which its task it to read business PRD or user prompt,  read our mobile code base and create an automation script based on it, execute it and troubleshoot it if there is an error. Took some time and attempts but it finally running smoothly and I dont even need to worry about token any longer:D.



In summary, I really happy about what I can achieve with OpenCode. Definitely I'm not utilizing their 100% potential yet, but I will keep exploring and share my findings here. I also considering to use the Go plan which start from $5 per month to see what improvement it gets on paid version. See you on next one!
